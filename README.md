# yolo_object_detection

## Project Description

This project focuses on **real-time object detection using YOLO (You Only Look Once)**. The system can detect and identify multiple objects from images, videos, or live webcam input.

Detected objects are displayed with **bounding boxes, object labels, and confidence scores**.

## Features

- Real-time object detection
- Detects multiple objects simultaneously
- Displays bounding boxes
- Shows object names and confidence scores
- Supports images, videos, and webcam input

## Technologies Used

- Python
- YOLO
- OpenCV
- NumPy

## How It Works

1. Provide an image, video, or webcam input.
2. YOLO processes the input.
3. The model detects objects in each frame.
4. Bounding boxes are created around the detected objects.
5. Object labels and confidence scores are displayed.
